# Мобильное приложение: учитель, ученик и родитель

Настоящее приложение (Expo, React Native) для iPhone и Android. Работает с тем же сервером и теми же данными, что и программа для компьютера (папка `server` в проекте журнала). Учитель может вести журнал и с телефона, и с компьютера: изменения видны на обоих.

**Учитель:** вкладки «Расписание» (неделя, отметки «проведён» и «оплачен» одним нажатием, новый урок, перенос и отмена с причиной), «Ученики» (карточка, курс с кодами для ученика и родителя, участники, сброс пароля), «Оплата» (долги, «оплачено», напоминание), «Домашка», разбор запросов на перенос и доска урока. Работает при наличии интернета: данные берутся с сервера и сразу отправляются обратно.

**Ученик и родитель:** выбор «ученик или родитель», вход и регистрация, «Мои курсы» по коду от учителя, уроки, переносы с причинами, домашка (ученик отмечает «сдал(а)»), запрос на перенос урока, доска урока и доски прошлых уроков, смена пароля. Обновляется само раз в минуту и при открытии приложения, также можно потянуть список вниз.

## Как запустить

Нужен Node.js. Версии пакетов Expo часто меняются, поэтому проект создаётся свежим, а наши файлы кладутся поверх.

```
npx create-expo-app@latest zhurnal-mobile --template blank
cd zhurnal-mobile
npx expo install react-native-webview expo-secure-store expo-crypto
```

Затем скопируйте из этой папки в `zhurnal-mobile` с заменой: `App.js`, папку `src`, `app.json`. Запуск:

```
npx expo start
```

Откройте на iPhone приложение Expo Go из App Store и наведите камеру на QR-код (телефон и компьютер в одной сети). Для проверки этого достаточно.

Адрес сервера можно вписать в `src/config.js`, тогда ученики не будут его вводить.

## Как отдать ученикам

- iPhone: нужен аккаунт Apple Developer (99 долларов в год), сборка через `npx eas-cli build -p ios` и раздача через TestFlight или App Store.
- Android: `npx eas-cli build -p android` даёт файл .apk, его можно отправить напрямую, либо Google Play.
- Перед сборкой замените `com.example.zhurnal` в `app.json` на свой идентификатор.

## Что проверено, а что нет

Проверен обмен с сервером на настоящем сервере: вход, коды, курсы, домашка, переносы, запросы, синхронизация между двумя устройствами учителя, конфликты правок, удаление, участники курса. Сами экраны на телефоне я запустить не мог, поэтому первые запуски могут показать мелкие недочёты вёрстки.
